API Reference

Chat Endpoint

POST /v1/run
Send a message and get an enhanced response with memory, tools, and skills

Request Parameters

Parameter Type Required Description
user_id string Yes Your device user ID
input string Yes Your message or prompt
memory_scope string No Memory scope: user, workspace, conversation, global
provider string No LLM provider: openrouter, featherless, openai, anthropic
model string No Model name (e.g., openai/gpt-oss-120b:free)

Response Format

JSON 
{
  "conversation_id": "uuid",
  "skill": "analysis",
  "output": "Your response here...",
  "provider": "openrouter",
  "model": "openai/gpt-oss-120b:free",
  "tool_calls": [],
  "tool_results": [],
  "metrics": {
    "memory_hits": 3,
    "tool_count": 0,
    "usage": {
      "prompt_tokens": 150,
      "completion_tokens": 200,
      "total_tokens": 350
    }
  }
}

Memory API

Store and retrieve facts that models remember across conversations.

Store a Fact

POST /v1/memory
Store a fact in unified memory
cURL

Memory Kinds

  • identity: Facts about who the user is
  • preference: User preferences and settings
  • context: Contextual information about projects
  • secret: Sensitive information (encrypted)

Skills

Pre-built capabilities that route requests intelligently.

Available Skills

Skill Description Tools Overhead
analysis Deep reasoning with memory and web search web_search, memory 2-4ms
summary Quick summaries with web retrieval web_search 1-2ms
code Programming tasks with code execution code_exec, math 2-3ms
research In-depth research with multiple sources web_search, deep_search 3-4ms
math Calculations and numerical analysis math_exec 1ms

Error Handling

Common Errors

Status Error Solution
401 Unauthorized Check your Aurora key is valid and not expired
400 Bad Request Verify all required parameters are provided
429 Rate Limited Wait before making more requests
500 Server Error Try again or contact support

Best Practices

Security

  • Never commit API keys to version control
  • Use environment variables for sensitive data
  • Rotate keys regularly
  • Use different keys for dev/prod environments

Performance

  • Cache memory facts to reduce API calls
  • Use appropriate memory scopes
  • Enable only needed skills
  • Batch requests when possible

Reliability

  • Implement exponential backoff for retries
  • Handle timeouts gracefully
  • Log all API interactions
  • Monitor error rates
