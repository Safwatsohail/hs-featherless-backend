    Quick Start

    Replace your raw API key with your Aurora key. Same endpoints, now stateful.

    Chat with Memory & Skills

    POST /v1/run — auto-routes to the best skill, recalls memory, executes tools.

    A/B Compare Raw vs Enhanced

    POST /v1/compare — runs both raw and enhanced in one call, returns delta metrics.

    Store & Retrieve Memory

    Memory is shared across all Aurora keys for the same user_id.

    Invoke a Specific Skill

    POST /v1/skills/{name} — force a specific skill instead of auto-routing.
